# パイロット前後移動と入力契約

## 対象と力学境界

パイロットの身体移動は機体前後方向の1自由度とする。パイロットを除く機体の固定重心を構造datum $O$ としてFRD軸を定義し、主翼、尾翼、接触点、パイロット眼位置の基準座標をこのdatumから保持する。機体は剛体、パイロットは機体に対して回転しない質点とする。パイロット相対位置 $x_p$、速度 $\dot x_p$、加速度 $\ddot x_p$ を扱う。移動可能範囲、質量、最大速度・加速度、初期位置は検証済みAircraftModelに含める。数値は機体モデルと操作試験に基づきBPG-002/006で確定する。

合成重心 $G$ と慣性テンソルはパイロット位置から導出する。機体質量 $m_a$、パイロット質量 $m_p$、パイロット位置 $r_p^B=(x_p,0,z_p)$ を用い、$z_p$ は機体モデルで固定する。

scenario inputが合成重心position/ground velocityを指定する場合、初期pilot stateとattitude/angular rateからdatum $O$ のlaunch stateへ逆変換する。変換後のpilot position/velocityはAircraftModelのrange検証を通す。windをground velocityへ暗黙に加算しない。

```math
M=m_a+m_p,\qquad r_G^B=\frac{m_p r_p^B}{M}
```

機体の$O$まわりの固定慣性を $I_a$ とする。$d_a=-r_G^B$、$d_p=r_p^B-r_G^B$ として、
合成重心まわりの慣性テンソルを平行軸の定理から導出する。

```math
I_G=I_a+m_a\left(\lVert d_a\rVert^2 I_3-d_a d_a^T\right)
       +m_p\left(\lVert d_p\rVert^2 I_3-d_p d_p^T\right)
```

機体構造上の固定点 $i$ は $r_{Oi}^B$ を保持する。積分状態は構造datum $O$ の位置・対地速度、機体姿勢・角速度、$x_p,\dot x_p$ とする。固定点と合成重心の位置は次式で導出する。

```math
p_i^N=p_O^N+R_{NB}r_{Oi}^B,\qquad
p_G^N=p_O^N+R_{NB}r_G^B
```

```math
v_i^N=v_O^N+R_{NB}(\omega^B\times r_{Oi}^B),\qquad
v_G^N=v_O^N+R_{NB}(\omega^B\times r_G^B+\dot r_G^B)
```

これらは点の運動学的関係である。合成重心の状態を必要とする診断では上式を使い、固定形状の座標原点を移動後の重心へ追従させない。

内部質量の相対運動は合成系の線形・角運動量に寄与する。$v_O^B=R_{NB}^Tv_O^N$、$\dot r_p^B=(\dot x_p,0,0)$ とし、機体の$O$まわりの固定慣性テンソルを $I_a$ とすると、合成系の運動量は次式である。

```math
P^B=Mv_O^B+m_p(\omega^B\times r_p^B+\dot r_p^B)
```

```math
H_O^B=I_a\omega^B+m_p r_p^B\times(v_O^B+\omega^B\times r_p^B+\dot r_p^B)
```

外力 $F^B$ と$O$まわりの外部moment $M_O^B$ は、重力を含め全質量要素・作用点から評価する。運動方程式は次の収支から導出する。$O$ は移動するため、角運動量収支には原点輸送項が入る。

```math
\dot P^B+\omega^B\times P^B=F^B,\qquad
\dot H_O^B+\omega^B\times H_O^B=M_O^B-v_O^B\times P^B
```

各RK4 stageで $x_p,\dot x_p,\ddot x_p$ を評価し、上式を連成して並進・角加速度を解く。内部駆動力を外力へ重複計上しない。$m_p=0$ または身体運動がない場合の退化ケース、無外力時の全運動量・角運動量、一般3次元姿勢での収支を検証する。重心位置と慣性を更新するだけの準静的近似は初期モデルに採用しない。
各stageの連成系は質量・慣性・位置・速度・加速度の有限性と、行列の数値的可逆性を検査する。
失敗時は型付きエラーを返し、部分更新した状態を公開しない。内部駆動はエネルギーを投入できるため、
身体移動中の機械的エネルギー保存を要求しない。

[参照Issue](https://github.com/tokutori/simulator-prototype-1/issues/1)は縦運動の連成式と検証候補を提供する。対象は平面縦運動であり、本ゲームの一般6DoFに対する成立性は別途評価する。数式・実装・操作割当を本ゲームの確定仕様として転用しない。

## 位置指令と入力機器

身体移動の論理指令は機体datum上の**目標前後位置**とする。実位置は速度・加速度・移動範囲の制約を持つ運動モデルから得る。位置の瞬間的な変更を禁止する。キーボードは増加・減少操作の保持時間を固定tickで積算して目標位置を更新し、キー解放時は目標を保持する。キーリピート回数や描画frame数で更新しない。ゲームパッドの校正済み軸は許可範囲の絶対目標位置へ写像する。スティック中立は校正済み中立位置を指す。

binding、軸方向、dead zone、校正、感度は変更可能な機器設定とする。Flight開始時に機器設定を固定する。設定の保存・検証・再割当、重複割当の通知はBPG-007/017で扱う。機器固有の値は、tickごとの機器非依存な `PilotCommand` へ変換する。`PilotCommand` は舵の論理指令と身体の目標位置を別フィールドで保持する。舵入力が舵角・姿勢目標・角速度目標のいずれを意味するかはcontroller modeごとに明記し、物理へ曖昧な `pitch` 値を渡さない。

Rust coreは位置目標から縦加速度を生成する。目標との距離を$d=|x_t-x|$、最大加速度を$a_{max}$、最大速度を$v_{max}$とすると、制動可能速度は次式とする。

```math
v_t=\operatorname{sgn}(x_t-x)\min\left(v_{max},\sqrt{2a_{max}d}\right)
```

要求加速度は$(v_t-\dot x)/\Delta t$を$[-a_{max},a_{max}]$へ制限する。目標方向の速度が制動可能速度以上の場合は、目標方向と逆向きに最大加速度を適用する。停止距離と残距離が1 tickの停止距離以下になった状態では速度0へ収束させる。policyのtimestepは100 Hz tick以下とする。
現在速度の停止距離が進行方向の移動限界までの距離を超える場合、物理的に復帰不能なstateとして型付きerrorを返す。位置や速度を暗黙にclampしない。

同時に有効な操縦機器は1つとし、選択機器の値だけを採用する。機器切替、切断、非表示化、UI overlayへの遷移では保留中の押下・軸値を破棄し、身体目標は直前の有効値に保持する。再接続では中立確認後に明示的に入力を再取得する。絶対位置軸へ切り替える際は現在目標との不連続を防ぐ同期操作を要求する。Menu操作イベントを同じtickのFlight指令へ転用しない。標準mappingと未対応機器の個別bindingを区別する。

FBW authorityの混合は同じ舵操作対象の指令に限定する。初期契約では身体の位置目標は選択された操縦機器から直接与え、FBWは舵を制御する。Automatic中も身体位置指令は独立して有効であり、入力がない場合は最後の目標位置を保持する。身体への自動指令を将来追加する際は、権限・調停・比較条件を独立に定義する。

## 検証と記録

初期身体位置・速度、目標位置列、実位置・速度・加速度、合成重心offsetと質量特性の導出値を記録・検証する。Replayは実位置からpilot poseと視点を再現する。初期状態、AircraftModel、Environment、舵入力列、身体目標位置列、刻みが同じ場合の決定性を検証する。身体指令だけを変更したケースでは質量分布と軌道が変化することを確認する。

BPG-002/006では内部移動中の無外力運動量・角運動量、左右非対称姿勢での慣性連成、移動限界、入力の急変、数値収束、全系100 Hzの誤差を検証する。BPG-007/017は機器切断・切替、binding再設定、tick割当、UI競合を検証する。BPG-019は身体状態と終端時刻の整合を検証する。上記の収支から得る実装用の加速度式と機体モデルの適用範囲は対象Issueで数値検証する。
